# WORKLOG — EduHub (ВКР, текущий этап)

> **Handoff:** после правок — `git commit` + `git push`; на другом ПК — `git pull`. История чата Cursor не переносится; ориентир — **этот файл** + `reports/vkr/`.

## 0) Быстрый старт с любого ПК (после `git pull`)

1. Ветка: **`prediploma-journal`**
2. `.venv` → `pip install -r requirements.txt`
3. `python manage.py migrate`
4. `python manage.py seed_demo` (опционально, демо-данные)
5. `python manage.py runserver`

## 1) Решения руководителя и сроки

- **Приоритет:** формальный **текст ВКР** к сдаче; код — по минимуму, только под описанные сценарии.
- **Деплой / полный QA** — не в фокусе; проверка в **§3.6**, перспективы в **§3.7** и заключении.
- В тексте: **прототип**, не «промышленная система»; Payment / полное МЗ — перспектива.

## 2) Подход

1. Текст ВКР в `reports/vkr/Гураль … финальный вариант на проверку.docx`.
2. Код и ER-диаграмма должны **совпадать** с текстом (без Payment; есть MessageThread / Message).
3. Перед сдачей: список источников (ОС ТУСUR, приложение Д), реферат (счётчики), порядок приложений Б→А.

### Редактура текста

- Естественный инженерный тон, привязка к МАОУ «Томский Хобби-центр».
- Не завышать: «готовое к внедрению», жёсткие формулировки по 152‑ФЗ без оговорок.
