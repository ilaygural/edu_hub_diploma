# WORKLOG — EduHub (преддиплом)

## 0) Быстрый старт с любого ПК (обязательно после git pull)
1. Переключиться на рабочую ветку:
   - `git checkout prediploma-journal`
   - `git pull`
2. Поднять окружение:
   - активировать `.venv`
3. Синхронизировать БД с кодом:
   - `python manage.py showmigrations accounts`
   - `python manage.py migrate`
4. Проверка запуска:
   - `python manage.py runserver`
