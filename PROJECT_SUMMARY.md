# Краткий конспект проекта EduHub

## С чего начать (handoff)

1. Прочитать **[WORKLOG.md](WORKLOG.md)** — актуальная цель этапа и следующий шаг.
2. Код: корень проекта **`django_edu_hub/`**, настройки **`config/`**, вход пользователей **`users/`** (`/users/login/`, выбор роли и т.д.), бизнес‑сущности **`accounts/`** + **`schedule/`**, публичная часть курсов **`core/`**.
3. Тексты и схемы: **`reports/`** — разнесено по этапам:
   - **`reports/tech/`** — технологическая практика;
   - **`reports/prediploma/`** — преддипломная (архив/источник формулировок для ВКР);
   - **`reports/vkr/`** — черновик и материалы ВКР;

   - **`reports/assets/`** — общие изображения (диаграммы и т.п.);
   - **`reports/draft/`** — при необходимости черновики «в работе» (может дублировать содержимое подпапок).
   - При наличии папки **`reports/Преддипломная практика/`** — вспомогательные материалы «на печать», не обязательна для сборки проекта.

## 📁 Общая структура проекта

Django-проект с модульной архитектурой:

```
django_edu_hub/
├── config/          # Настройки проекта (settings, urls, wsgi/asgi)
├── users/           # Аутентификация, регистрация, профиль, выбор роли
├── accounts/        # Профили и сценарии (Pupil, Teacher, Parent, менеджер, заявки)
├── core/            # Курсы, теги, публичные страницы, KPI
├── schedule/        # Группы, расписание, посещаемость, платежи
├── templates/       # Общие шаблоны (base.html, home.html, includes/...)
└── static/          # Статические файлы (css/...)
```

### Приложения Django:
- `users` — вход, регистрация, смена пароля, выбор роли
- `accounts` — профили пользователей (Pupil, Teacher, Parent), заявки, кабинеты
- `core` — курсы и теги
- `schedule` — группы, расписание, посещаемость, платежи

## 🗄️ Модели данных

### `accounts` — Профили пользователей

#### **Pupil** (Ученик)
- `user` — OneToOne(User), связь с Django User
- `birth_date` — дата рождения
- `phone` — телефон
- `address` — адрес
- `status` — статус (ACTIVE, INACTIVE, GRADUATED)
- `enrolled_date` — дата регистрации
- `updated_at` — последнее обновление
- **Свойства:** `full_name`, `email`
- **Менеджер:** `PupulManager` с методом `active_or_enrolled_after()`

#### **Teacher** (Преподаватель)
- `user` — OneToOne(User)
- `qualification` — квалификация
- `specialization` — специализация
- `experience_years` — стаж (лет)
- `phone` — телефон
- `office` — кабинет
- `is_active` — флаг активности
- `created_at`, `updated_at` — временные метки
- **Свойства:** `full_name`

#### **Parent** (Родитель)
- `user` — OneToOne(User)
- `children` — ManyToMany(Pupil), связь с детьми
- `phone` — телефон
- `work_place` — место работы
- `additional_contacts` — дополнительные контакты
- `created_at`, `updated_at` — временные метки
- **Свойства:** `full_name`

---

### `core` — Курсы и теги

#### **Tag** (Тег)
- `name` — название тега (уникальное)
- `slug` — URL-слаг (уникальный)
- Метод: `get_absolute_url()`

#### **Course** (Курс)
- `title` — название курса
- `description` — описание
- `price` — цена (Decimal)
- `slug` — URL-слаг (уникальный, индексируется)
- `code` — код курса (уникальный)
- `time_create`, `time_update` — временные поля
- `is_published` — статус публикации (DRAFT/PUBLISHED)
- `tags` — ManyToMany(Tag), связь с тегами
- `teachers` — ManyToMany(Teacher), связь с преподавателями
- **Менеджер:** `published` — для получения только опубликованных курсов
- Метод: `get_absolute_url()`
- **Индексы:** по `time_create` и `slug`

---

### `schedule` — Расписание и группы

#### **Group** (Учебная группа)
- `name` — название группы
- `description` — описание группы
- `start_date` — дата создания
- `end_date` — дата окончания
- `status` — статус (ACTIVE, COMPLETED, PLANNED)
- **Методы:**
  - `get_active_pupils()` — активные ученики (за последние 7 дней)
  - `has_active_pupils()` — проверка наличия активных учеников
  - `active_pupils_count()` — количество активных учеников

#### **Enrollment** (Зачисление)
- `pupil` — ForeignKey(Pupil)
- `group` — ForeignKey(Group)
- `date_from` — дата зачисления
- `date_to` — дата отчисления (nullable)
- **Свойство:** `is_active` — проверка активности зачисления

#### **Attendance** (Посещаемость)
- `pupil` — ForeignKey(Pupil)
- `lesson_date` — дата занятия
- `status` — статус (PRESENT, ABSENT, LATE)
- `notes` — примечания
- **Свойство:** `is_present` — проверка присутствия

#### **Schedule** (Расписание занятий)
- `group` — ForeignKey(Group)
- `lesson_date` — дата занятия
- `start_time` — время начала
- `end_time` — время окончания
- `topic` — тема занятия
- `teacher` — ForeignKey(Teacher, nullable) — преподаватель занятия
- **Свойство:** `duration` — длительность в минутах
- **Индекс:** по `lesson_date`

#### **Payment** (Платеж)
- `pupil` — ForeignKey(Pupil)
- `amount` — сумма (Decimal)
- `payment_date` — дата оплаты
- `purpose` — назначение (TUITION, MATERIAL, OTHER)
- `notes` — примечания
- `created_at`, `updated_at` — временные метки
- **Свойство:** `is_recent` — проверка, что платеж за последние 30 дней

## 🔗 Связи между моделями

### Основные связи:
1. **User ↔️ Профили:** OneToOne (Pupil, Teacher, Parent)
2. **Teacher ↔️ Course:** ManyToMany (преподаватель может вести несколько курсов)
3. **Parent ↔️ Pupil:** ManyToMany (родитель может иметь несколько детей)
4. **Pupil ↔️ Group:** через Enrollment (ученик может быть в нескольких группах)
5. **Group ↔️ Schedule:** ForeignKey (группа имеет множество занятий)
6. **Schedule ↔️ Teacher:** ForeignKey (занятие ведет преподаватель)
7. **Pupil ↔️ Attendance:** ForeignKey (ученик имеет множество записей посещаемости)
8. **Pupil ↔️ Payment:** ForeignKey (ученик имеет множество платежей)
